# Page Content Plan — Phase 1 Output
## خطة محتوى الصفحات

For EVERY must-have page listed in `01-profile.md`, define its required
sections and what actual content (not placeholder) goes in each — derived
from the client's real services, goals, and tone. This is what Phase 2
reads to build each page's first draft. No design/style decisions here
(palette, fonts, layout treatment) — content and structure only.

## Notes

- If the client's profile doesn't have enough real content for a section
  (e.g. no testimonials given), mark it as "Needs client input" rather
  than inventing fake testimonials/numbers.
- This plan should be specific enough that Phase 2 doesn't have to guess
  what belongs on each page — it only has to decide how it looks.
